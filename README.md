# Windows Rekenmachine (React + Vite)

Webapp die de standaardrekenmachine van Windows nabootst.

## Installatie en gebruik

```bash
npm install
npm run dev      # ontwikkelserver
npm test         # unittests (vitest)
npm run build    # productiebuild in dist/
```

## Functies
- Basisbewerkingen: optellen, aftrekken, vermenigvuldigen, delen
- Procent, vierkantswortel, kwadraat, omgekeerde waarde, teken wisselen
- CE, C en backspace
- Toetsenbordondersteuning (cijfers, + - * / Enter, Escape, Backspace)
- Foutmelding bij delen door nul
